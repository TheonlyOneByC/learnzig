Downloading Zig for non mobile users

On a PC you also have many great options:
Lightweight text editor: VS Code
Heavyweight full IDE: CLion

Downloading Zig for VS Code

press Ctrl + Shift + X on Windows and Cmd + Shift + X on macOS to get to the plugins menu from there in the top bar you can search for Zig and download the first one

Setting up Zig for CLion

After you have downloaded Zig and extracted it on your computer, navigate your way to settings menu(shortcut above) find Languages & Frameworks; find Zig, Toolchain and Server field, for the toolchain point to your folder where your Zig intepreter lives(not the .exe) After you've done that check, confirm it works by checking if the field does say anything other than zig followed by numbers The server refers to the server handling autocomplete, it's optional to download but if you do wanna download it you can press the auto download option for it near the same field

Running Zig code

After you have done the steps above you need to add zig to your path you can do that by following a YouTube tutorial, after you've done that you need to open your terminal navigate to your project cd "ProjectPath" and run zig init zig init generates a default project template(build.zig) and a sample source file To simplify what zig build does it construct a dependency of steps(e.g. in what order to run the files), it also looks for build.zig in the root folder so it can run and compile the script using a minuture internal runner Zig build also links specfied libaries in build.zig, in compile source files into exes or libaries, that is not the only purpose of build.zig it does a lot more which we will get onto in future lessons. After you have run zig build and pressed run in your IDE you may see that no output is generated this is because zig build doesn't actually run the code it only builds it , to actually run the code you must use zig build run If you are doing quick projects you can instead use zig run which does not need zig build
